*** branch =removable_media_z2w_photopainter=
the PCB in waveshare's photopainter (for the rpi zero 2w) has an uninterruptible power supply and real time clock built in. great for prototype.
- no web app: user plugs in flashdrive with pictures they want to display and a settings.txt.
- python handles device detection with pyudev, using a file descriptor reader (asyncio add_reader). script is set up as a systemd service.
- logic for desired/intended behavior in python
  - image converstions are all (re)done & a sqlite db is created /every time you plug in the drive/. conversions are synchronous, not interrupted.
  - makeshift support for RTC: if seconds per frame setting exceeds a tolerance, device powers off and wakes to draw next frame
- python configured as a systemd service
- no multiple albums
- photopainter has no exra buttons, want to add them
